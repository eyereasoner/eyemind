# Pell equations in Logical English

*Large exact integers, a recursive recurrence and direct polynomial checks.*

[pell-equation-le.le](https://github.com/eyereasoner/eyemind/blob/main/examples/pell-equation-le.le) · [output](https://github.com/eyereasoner/eyemind/blob/main/examples/output/pell-equation-le.le) · [proof](https://github.com/eyereasoner/eyemind/blob/main/examples/proof/pell-equation-le.js) · [check](https://github.com/eyereasoner/eyemind/blob/main/examples/check/pell-equation-le.js) · [playground](https://eyereasoner.github.io/eyemind/playground/#example=pell-equation-le)

## The question

Which pairs generated by twenty-four recurrence steps satisfy
X*X - 2*Y*Y = 1 with X greater than 2^53? These values cannot all be represented
exactly as JavaScript binary64 numbers.

## What we tell eyemind

The initial pair is (1, 0). Multiplication by 3 + 2*sqrt(2) gives the integer
recurrence U = 3X + 4Y and V = 2X + 3Y. A step counter bounds the computation.

A separate rule recomputes X*X - 2*Y*Y with exact integer multiplication and
subtraction. It reports a pair only if this computed residual is exactly one
and X exceeds the stated threshold. No square-root approximation is used.

## What eyemind concludes

The checked LS answers are:

```js
solution(34761632124320657, 24580185800219268, 1)
solution(202605639573839043, 143263821649299118, 1)
solution(1180872205318713601, 835002744095575440, 1)
```

The third argument is the computed residual. The conclusions keep the full
integer values in both their `.le` rendering and their JavaScript check report.

## What the proof establishes

The saved proof is **checked** against the compiled LS program, including the
exact computations and the complete answer set for the finite recurrence.
The same proof checks against the standalone JavaScript compilation. This is
not an induction proof that the recurrence always works, or a proof that it
enumerates every positive solution of the Pell equation.

## Try it

```sh
node bin/eyemind.js examples/pell-equation-le.le
node bin/eyemind.js --program examples/pell-equation-le.le > /tmp/pell-equation-le.js
node bin/eyemind.js --to le /tmp/pell-equation-le.js
node bin/eyemind.js --proof examples/pell-equation-le.le
node bin/eyemind.js --check-proof examples/proof/pell-equation-le.js examples/pell-equation-le.le
```

Reduce the iteration limit to 21: no generated X passes the threshold.
Increase it to 25: one more large solution appears. Integer operations remain
exact; changing literals to floats asks for a different computation.
