eyemind — reasoning you can see.

Every case of the conformance suite, run against eyemind in your browser and checked against the specification.

Each case runs eyemind's command line on the files it names, in a directory of its own, and compares what eyemind prints and its exit code with what the specification requires. In an expected line, … stands for text the specification leaves to the implementation. Run the same cases against any implementation with node conformance/run.js --command "…".

Powered by eyemind, a dependency-free JavaScript rule language with forward and backward reasoning and checkable proofs.
